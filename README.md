# Riju watchlist repository

This directory is the root of the existing [rijuphilip07/shopping-list](https://github.com/rijuphilip07/shopping-list) repository. Push it to `main`, then enable GitHub Pages from `main` and `/ (root)` to publish `index.html` at `https://rijuphilip07.github.io/shopping-list/`. The site reads `data/products.json` and displays current prices, targets, and recent history. Product changes come from the Hermes skills through `scripts/riju.py`; the page itself is read-only. See the parent `README.md` for setup and scheduling.
